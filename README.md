# Demantoid Drop

Full-colour Python 3 neon plinko arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a hopper across the trench. Drop spinning gems through a peg field.
Land the 500 jackpot slot to keep the streak alive. A / D steer. Space drops.

## Play

```
pip install -r requirements.txt
python3 demantoid_drop.py --play
```

Interactive controls: `A` / `D` or arrows move the hopper, `SPACE` / `W` drop a gem, `R` restart, `ESC` quit.

## Record a 9:16 reel

```
python3 demantoid_drop.py --record
```

Writes `/home/workdir/artifacts/demantoid_drop_ElbowOS.mp4` (1080x1920, 15s, 30fps, h264).
